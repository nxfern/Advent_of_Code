# Advent of Code

This repository contains my solutions for all respective Advent of Code years worked on, ordered by year. Each folder contains each respecting day as a .py file. Puzzle inputs not provided/posted as per AOC guidelines. I went through earlier in 2026 and refactored old solutions and am pretty happy with what I have done, though I still have much to learn as my solutions are very far from perfect! I get great satisfaction from reviewing other people's solutions to these problems as I consider most people I see to be far more creative (as well as better programmers) than myself!

This repository also contains a .gitignore file that you are free to modify to your own liking should you choose to use it.
